# 复盘记录

本目录存放每日复盘原始内容与提炼摘要。

## 目录结构

```
reviews/
├── INDEX.md                  # 复盘索引（按日期快速浏览）
├── YYYY-MM-DD.md             # 当日原始复盘
└── insights/
    └── YYYY-MM-DD-summary.md # 当日要点提炼与讨论结论
```

## 使用方式

在 Cursor 对话中：

- `/daily-review` — 调用复盘技能
- 或直接说：「帮我复盘今天」「提炼一下今天的要点」「讨论一下今天的复盘」

## 命名规范

- 日期格式：`YYYY-MM-DD`（如 `2026-06-08`）
- 每天一份原始复盘，一份要点摘要（提炼或讨论后生成）

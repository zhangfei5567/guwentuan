# 要点提炼格式

将复盘内容提炼为以下结构，写入 `reviews/insights/YYYY-MM-DD-summary.md`：

```markdown
# YYYY-MM-DD 复盘要点

## 核心成果

1. 
2. 

## 关键问题

1. 
2. 

## 认知升级

1. 

## 决策记录

| 决策 | 背景 | 预期结果 |
|------|------|----------|
|      |      |          |

## 行动项

| 事项 | 优先级 | 截止时间 | 备注 |
|------|--------|----------|------|
|      | 高/中/低 |        |      |

## 模式信号

- （跨日复盘时关注：重复卡点、行为模式、情绪趋势）

## 一句话总结

> （用一句话概括今天）

---

## 讨论结论

（讨论模式结束后填写）

### 关键洞察

- 

### 调整建议

- 

### 下次验证

- 
```

## 提炼原则

1. **忠实原文**：只提炼复盘中有依据的信息，不添加用户未提及的内容。
2. **去重合并**：相似条目合并，保留最有信息量的表述。
3. **区分事实与推断**：推断需标注「（推断）」。
4. **行动项可执行**：每条行动项应是具体行为，避免模糊目标。
5. **模式信号需证据**：指出重复模式时，引用本次或历史复盘中的具体表现。
